# engine-sim — Docker/Podman API simulator

A **stateful, drift-faithful** simulator of the Docker Engine HTTP API, with a
selectable `--profile` (`podman` | `docker`). It's a deterministic, VM-free gate
for the Podman-support work: point arcane's Moby client (or the Go
`-tags integration` tests) at its unix socket and assert the code handles each
documented Docker↔Podman drift.

## Why

Carrying a `podman machine` VM around for every test is slow and heavy. This
simulator gives the same signal deterministically, runs in CI, and is the
**executable form of `docs/podman/drift-audit.md`** (see `engine_sim/drift.py`).
The `podman` profile is grounded in **real responses captured** from a live
rootless Podman 6.1.1 (`fixtures/podman/`, regenerated by `probe.sh`).

## Architecture

```
engine_sim/
  db.py         SQLAlchemy engine/session (SQLite; StaticPool so state is shared across threads)
  models.py     ORM state tables: Container, Image, Volume, Network, ExecInstance, Event
  store.py      the fake engine — CRUD + real lifecycle transitions + event emission + serializers
  profiles.py   podman (fixture-backed) / docker (doc-backed) behavior + drift toggles
  drift.py      registry of documented drifts (id, doc citation, docker vs podman behavior)
  api.py        FastAPI app: version-prefix strip, routers per resource, NDJSON events
  __main__.py   CLI (uds or TCP)
fixtures/<profile>/   real captured API responses
probe.sh              E2E probe that regenerates fixtures from a live engine
```

State is real: `create` shows up in `list`, `start` flips `State.Status` to
`running`, `stop` sets `ExitCode`/`exited`, `remove` deletes — all in SQLite.

## Run

```sh
cd tools/api-simulator
uv run python -m engine_sim --profile podman --socket /tmp/engine-sim.sock
# then:
DOCKER_HOST=unix:///tmp/engine-sim.sock docker version   # or arcane's client
```

Or via just (from repo root):

```sh
just sim podman              # boot the simulator
just test-sim podman         # boot it + run the Go engine gates against it, then tear down
```

## Regenerate fixtures from a real engine

```sh
DOCKER_HOST=unix://…/podman.sock ./probe.sh podman     # or `docker` against a Docker host
```

## Drifts encoded so far

Engine identity (Components name), API-version floor (1.44), empty
`Buildkit-Version` header (B5/B6), `MemorySwappiness` dropped on cgroup v2 (B2),
`Rootless`/`SecurityOptions` (B1/B3), default-network aliased to `bridge` over
compat (refines D2), `/swarm` → 404 vs 503 (B4), storage driver/root. Extend
`drift.py` + `profiles.py` as phases land.
